Home Designer — help

Drawing

  • ⬚ Room (B): drag a rectangle → a named room with four walls. ▢ Area (A): same without walls (garden, parking, open kitchen).
  • ▭ Wall (W): click, click, click… Double-click, right-click or Esc to stop. Hold Shift for 45° steps, Alt to switch off snapping.
  • Exact lengths, fast: while drawing a wall just type the length (e.g. 4.5, 450cm, 12'6) and press Enter — the wall goes in the direction of the mouse. Select an existing wall, type a number, Enter → it is resized and the joined walls follow. With the Room tool type 4x3.5 Enter.
  • Two wall types: Exterior (default 23 cm / 9″) and Interior (default 11.5 cm / 4.5″). Switch with the Ext/Int button or E. Change the two thicknesses in Design settings — all walls of that type update. “Auto-detect” marks walls that touch the outside as exterior.
  • ⬠ Polygon room (P): click the corners, click the first corner (or Enter) to close. Good for L-shaped rooms.
  • Doors & windows: pick one from the catalog and click on a wall. Drag it to slide along the wall; R flips the door swing.
  • Furniture: pick from the catalog and click on the plan. R rotates 90° (Shift+R: 15°). Shift+click places several. Wall items (TV, AC, wardrobes…) snap flat against the nearest wall.

Tracing a sketch, photo or plan

  • Import / Export → Trace over an image (or Design settings → Trace image). Upload a file or paste a web URL.
  • Click both ends of something you know the length of (a wall, the plot width) and type the real length — the image is scaled.
  • Lower the opacity, then draw walls (W) and rooms over it. “Move image” lines it up. The image is saved inside the design.

Real 3D models

  • Select any item → 3D model → Browse free models (522 CC0 models from Poly Haven) or Upload .glb (Sketchfab, Kenney, Blender exports…).
  • The model is stretched to the item’s width / depth / height; Use model’s real size copies its true size. Use for every … applies it to all items of that type.
  • Downloaded and uploaded models are stored in designs/models/ — commit that folder together with your designs.

Annotating places

  • Select a room to name it, pick its type, colour, floor finish, paint and notes.
  • 📍 Note pin (N): numbered notes anywhere (“extra socket here”, “leak check”). T label: free text. ↔ dimension (D).
  • Every item, door, window and wall has a label and notes field — brand, price, link, status.
  • The Places & notes tab lists everything; the Schedule tab counts items per category and exports CSV.

Saving

  • Save (Ctrl+S) writes home_designer/designs/<name>.json when you run start.sh. Commit those files to keep them in git.
  • Every save keeps the previous version in designs/.history/. Your current work is also auto-saved in the browser.
  • Without the server (e.g. static hosting) designs are kept in this browser — use Export to download them.
