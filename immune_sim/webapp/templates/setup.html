Setup

One button each. Every dataset is already in this repository, gzipped, so the first two options need no network at all.

If you only want to use the thing: press Set up everything. It trains all three epitope models from the bundled data and then checks the dynamic model against the held-out human subjects, so you can see for yourself that it works before you trust it. About ten minutes, offline.

What is on disk

Green means built and current. Amber means something it was computed from has been rebuilt since, so it is out of date. Grey means not built yet.
